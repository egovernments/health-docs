# Language Selection

## Overview

Allows users to select their preferred language for the app UI. It enables users to easily switch between the languages, which enhances the user experience.

* Select the preferred language between Portuguese, French, and English.

## Steps

* Select the preferred language from the options on the landing page of the app.
