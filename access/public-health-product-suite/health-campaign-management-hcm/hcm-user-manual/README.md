# HCM User Manual

The HCM User Manual explains how to use the Health Campaign Management app in day-to-day field operations. It covers core support functions such as login, sync, help, navigation, and project selection.\
It also includes step-by-step guidance for campaign workflows, common actions, and feature-specific tasks. This section helps field teams, supervisors, and program staff use the app correctly during campaign delivery.
