# Validate & Approve Population Data

**Roles involved:**

* Population Data Approver
* National Population Data Approver

***

### Step 1: Select Language & Log In

1. Select a preferred language:
2. Click **Continue** to open the login page.
3. Enter:
   * **Username**
   * **Password**
   * **City**
4. Click **Login**.

<figure><img src="../../../../../.gitbook/assets/image (45).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
📌 _Note:_ User accounts are created by the system administrator and shared with respective users.
{% endhint %}

***

### Step 2: Access Assigned Microplans

1. After logging in, you will land on the **Home Page**.
2. Click on **My Microplans**.
3. You will see a list of microplans assigned to you.

<div align="left"><figure><img src="../../../../../.gitbook/assets/image (46).png" alt="" width="375"><figcaption></figcaption></figure></div>

#### Microplan Dashboard Details

* **Microplan Name**
* **Status**
  * Completed Setup – Ready for validation
  * Validation in Progress – Validation ongoing
  * Microplan Finalised – Estimation completed
* **Campaign Disease**
* **Campaign Type**
* **Distribution Strategy**
* **Action**

<div align="left"><figure><img src="../../../../../.gitbook/assets/image (47).png" alt="" width="375"><figcaption></figcaption></figure></div>

You can also search microplans using the **Microplan Name** search bar.

***

### Step 3: Select Microplan & Activity

1. Select the microplan you want to work on.
2. You will be redirected to the **Activity Selection** screen.
3. Click **Validate & Approve Population Data**.

<div align="left"><figure><img src="../../../../../.gitbook/assets/image (48).png" alt="" width="375"><figcaption></figcaption></figure></div>

{% hint style="info" %}
📌 _Note:_ Population data validation is mandatory before any other microplanning activity can proceed.
{% endhint %}

***

### Step 4: Review Population Validation Dashboard

You will see a list of villages/settlements under your jurisdiction.

#### Available Filters

* **Assignment**
  * Assigned to Me
  * Assigned to All
* **Validation Status**
  * Pending for Validation
  * Pending for Approval
  * Validated
* **Administrative filters** (district, block, etc.)

<figure><img src="../../../../../.gitbook/assets/image (49).png" alt=""><figcaption></figcaption></figure>

#### Village-Level Details

* Village Name
* Assignee
* Uploaded Total Population
* Confirmed Total Population
* Uploaded Target Population
* Confirmed Target Population
* Status Logs (who changed what, when, and why)

{% hint style="info" %}
📌 _Note:_ For SMC campaigns, age-wise population columns may also appear.
{% endhint %}

***

### Step 5: Validate Population Data (Population Data Approver)

1. Review the confirmed population data for villages.
2. If data is correct:
   * Select the villages.
   * Click **Validate**.
   * Optionally add a comment/reason.
3. The village status changes to **Validated**.

<figure><img src="../../../../../.gitbook/assets/image (53).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../../../../../.gitbook/assets/image (52).png" alt=""><figcaption></figcaption></figure>

***

### Step 6: Edit & Send for Approval (If Data Needs Correction)

1. If population data is incorrect:
   * Click **Edit** next to the confirmed population.
2. Update population values.
3. Add an optional comment/reason.
4. Submit the update.

<figure><img src="../../../../../.gitbook/assets/image (54).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
📌 The village status changes to **Pending for Approval** and is sent to the supervisor.
{% endhint %}

***

### Step 7: Approve or Reject Updates (National Population Data Approver)

1. Log in using the **National Population Data Approver** role.
2. Open **My Microplans** → select the microplan.
3. Go to **Validate & Approve Population Data**.
4. View villages under **Pending for Approval**.

<figure><img src="../../../../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>

#### Available Actions

* **Approve**
  * Accept the updated population data
  * Optional comment
*   **Send Back for Correction**

    * Reject the update
    * Provide a reason/comment



***

### Step 8: Review Validated Villages

* All validated villages appear under the **Validated** tab.
* National approvers can still send data back for correction if required.

***

### Step 9: Finalise Population Data (National Role Only)

Once all villages under the campaign boundary are validated:

1. The **Proceed to Finalise Population Data** button becomes available.
2. Click the button to finalise population data.
3. Confirm the action in the pop-up.

<figure><img src="../../../../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
📌 Finalised population data is locked and used for microplan estimation.
{% endhint %}

***

### Step 10: Completion

* A confirmation message indicates successful finalisation

<figure><img src="../../../../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

* Click **Go Back to Home** to return to the **My Microplans** dashboard.
* The population validation activity is now complete.
