# Microplanning User Manual

## Overview

This user manual section guides system administrators, population data approvers, facility boundary assigners, and microplan estimation approvers in using the Microplanning module for health campaigns.

## User Roles

<table><thead><tr><th width="150.94140625">Role</th><th>Description</th></tr></thead><tbody><tr><td><strong>System Administrator</strong></td><td>Responsible for setting up and configuring the microplanning platform, including selecting campaign boundaries, setting up data, and configuring microplan assumptions. This role operates at the national/country level.</td></tr><tr><td><strong>Population Data Approver</strong></td><td>Reviews, validates, and approves population data for the assigned jurisdiction (e.g., province, district). Approved data is used for microplan resource estimation.</td></tr><tr><td><strong>National Population Data Approver</strong></td><td>A national-level approver responsible for approving and finalising population data for villages or settlements within the campaign boundary.</td></tr><tr><td><strong>Facility Boundary Assigner</strong></td><td>Assigns facilities to their respective catchment boundaries within the assigned jurisdiction (e.g., province, district).</td></tr><tr><td><strong>National Facility Boundary Assigner</strong></td><td>A national-level user responsible for assigning facilities to catchment boundaries and finalising facility-to-catchment area mappings for villages or settlements within the campaign boundary.</td></tr><tr><td><strong>Microplan Estimation Approver</strong></td><td>Reviews, edits, and approves microplan estimations for the assigned jurisdiction (e.g., province, district).</td></tr><tr><td><strong>National Microplan Estimation Approver</strong></td><td>A national-level approver responsible for reviewing, editing, approving, and finalising microplan estimations for villages or settlements within the campaign boundary.</td></tr></tbody></table>
