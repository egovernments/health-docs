# Edit Campaign Data

## **Steps**

System admins can manage and update campaign data, such as Targets, Facilities, and Users, during an ongoing or upcoming campaign. This feature reduces the dependency on the Implementation Team and enables quicker adjustments.

#### **Pre-requisites**

Before editing campaign data, ensure that:

* You have access to the HCM Console.
* The campaign is either ongoing or in an ongoing state.
* You have the latest uploaded files for Target, Facility, and User data.

### **Update Boundary Data**

1. To select new boundaries for any campaign, navigate to the My Campaigns section from the main dashboard. Locate and select the campaign you wish to update. This will take you to the campaign summary screen.

2. On the My Campaign screen, click the Actions button and then select Edit Campaign Boundary Data from the dropdown. Add existing boundaries from the dropdown.

3. Upload and update Target, Facility, and User Data details. These updates are mandatory to ensure consistency in campaign data.

**To update target data -**

1. On the Update Target Data Screen, click on the Download Existing Data button to download the last successfully uploaded file used for creating the Target Data. Open the downloaded file and review the existing Target data.

<figure><img src="https://docs.digit.org/~gitbook/image?url=https%3A%2F%2Fcontent.gitbook.com%2Fcontent%2FTXGfwWeUzCL8CsU9R0tT%2Fblobs%2FSJdi9m8JxBRkkyPEtP33%2FScreenshot%25202024-08-26%2520at%252010.47.32%2520AM.png&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=87887870&#x26;sv=2" alt=""><figcaption></figcaption></figure>

2. On the Target Upload Screen, note that the Download Template button is disabled. Instead, download the last successfully uploaded file that was used to create the Target Data for the campaign. Open the downloaded file and review the existing data.

<figure><img src="https://docs.digit.org/~gitbook/image?url=https%3A%2F%2Fcontent.gitbook.com%2Fcontent%2FTXGfwWeUzCL8CsU9R0tT%2Fblobs%2FqM7bMffEyjqRYHPgexZP%2FScreenshot%25202024-08-26%2520at%252010.50.42%2520AM.png&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=800c7fe1&#x26;sv=2" alt=""><figcaption></figcaption></figure>

3. Once the new boundaries are added, upload the updated data. Ensure that the upload is successful and the changes are reflected in the campaign summary.

<figure><img src="https://docs.digit.org/~gitbook/image?url=https%3A%2F%2Fcontent.gitbook.com%2Fcontent%2FTXGfwWeUzCL8CsU9R0tT%2Fblobs%2FoQB5vTQvyDfiAdoFZI6a%2FScreenshot%25202024-08-26%2520at%252010.52.08%2520AM.png&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=ed2696b3&#x26;sv=2" alt=""><figcaption></figcaption></figure>

**To update Facility Data -**&#x20;

1. Go to My Campaigns in the HCM Console. Under My Campaigns, go to the campaign for which you want to edit Facility Data and under “Actions” click on “Edit Facility Data”.

<figure><img src="https://docs.digit.org/~gitbook/image?url=https%3A%2F%2Fcontent.gitbook.com%2Fcontent%2FTXGfwWeUzCL8CsU9R0tT%2Fblobs%2FrJx8b2flL7F6hPzADHT7%2FScreenshot%25202024-08-26%2520at%252010.53.36%2520AM.png&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=49ea055a&#x26;sv=2" alt=""><figcaption></figcaption></figure>

2. On the Update Facility Data Screen, click on the "Download Existing Data" button to download the last successfully uploaded file used for creating the Facility Data. Open the downloaded file and review the existing facility data.

<figure><img src="https://docs.digit.org/~gitbook/image?url=https%3A%2F%2Fcontent.gitbook.com%2Fcontent%2FTXGfwWeUzCL8CsU9R0tT%2Fblobs%2FiCWk2QysjCYZTx2Z267K%2FScreenshot%25202024-08-26%2520at%252010.54.27%2520AM.png&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=3dfcd67&#x26;sv=2" alt=""><figcaption></figcaption></figure>

3. If new boundaries are added to the campaign, these will be appended to the “List of Campaign Boundary” sheet. Review and update the facility status, boundary mapping, and create any new facilities as needed.&#x20;

{% hint style="info" %}
Note: Removal of existing boundary data is not allowed.
{% endhint %}

4. After making the necessary edits, save the Excel file. Return to the Facility Data Upload Screen and upload the updated Excel file. Ensure that the upload is successful and that the changes are reflected in the campaign summary.

<figure><img src="https://docs.digit.org/~gitbook/image?url=https%3A%2F%2Fcontent.gitbook.com%2Fcontent%2FTXGfwWeUzCL8CsU9R0tT%2Fblobs%2FyORgicfcktNLEgoPpyl8%2FScreenshot%25202024-08-26%2520at%252010.55.14%2520AM.png&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=9fc77696&#x26;sv=2" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Note on Deactivation/Deletion:

* If there are facilities that need to be deactivated or deleted, contact the Impel Team, as this action requires additional checks and cannot be performed through the Console.
{% endhint %}

**To update app user data -**

1. Navigate to My Campaigns in the HCM Console. Select the Actions button for that specific campaign, and in the dropdown that opens, select Edit App User Data.

<figure><img src="https://docs.digit.org/~gitbook/image?url=https%3A%2F%2Fcontent.gitbook.com%2Fcontent%2FTXGfwWeUzCL8CsU9R0tT%2Fblobs%2FOr0ZrXa0evMLOkMJ9fnf%2FScreenshot%25202024-08-26%2520at%252010.56.48%2520AM.png&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=96142fa7&#x26;sv=2" alt=""><figcaption></figcaption></figure>

2. On the Update App User Data Screen, click on the Download Existing Data button to download the last successfully uploaded file used for creating the App User Data. Open the downloaded file and review the existing App User data.

<figure><img src="https://docs.digit.org/~gitbook/image?url=https%3A%2F%2Fcontent.gitbook.com%2Fcontent%2FTXGfwWeUzCL8CsU9R0tT%2Fblobs%2F0GWXuxoYZ5YkzxDbpbGz%2FScreenshot%25202024-08-26%2520at%252010.57.47%2520AM.png&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=dcd5b184&#x26;sv=2" alt=""><figcaption></figcaption></figure>

3. If new boundaries are added to the campaign, these will be appended to the List of Campaign Boundary sheet. Review and update user roles, boundary mapping, and create any new users as needed.&#x20;

{% hint style="info" %}
Note: If a user is assigned to a boundary that has been deselected, update the boundary mapping for that user.
{% endhint %}

4. After making the necessary edits, save the Excel file. Return to the User Data Upload Screen and upload the updated Excel file. Ensure that the upload is successful and that the changes are reflected in the campaign summary.

<figure><img src="https://docs.digit.org/~gitbook/image?url=https%3A%2F%2Fcontent.gitbook.com%2Fcontent%2FTXGfwWeUzCL8CsU9R0tT%2Fblobs%2FoZIYZyYyBVsbcbOSsRm6%2FScreenshot%25202024-08-26%2520at%252010.58.37%2520AM.png&#x26;width=768&#x26;dpr=4&#x26;quality=100&#x26;sign=e1be7ceb&#x26;sv=2" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Note on Deactivation/Deletion:

* If the users need to be deactivated or deleted, contact the Impel team, as this action requires additional checks and cannot be performed through the Console.
{% endhint %}
