# Manage Boundary Data

## Steps

Programme managers can manage boundary data for specific campaigns. Boundaries can be created, edited, and managed using data from GeoPoDe or through custom ShapeFiles and Excel uploads.

### Access Boundary Management

#### Steps for Managing Boundary Data Using GeoPoDe

1. Log in to the HCM Console.
2. Navigate to the Boundary Management. Click on the Create New Boundary Data button.

<figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 9.54.20 AM.png" alt=""><figcaption></figcaption></figure>

3. Click on Get Boundary Data from GeoPoDe. The system fetches the available boundary hierarchy and data for your country.

<figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 9.58.32 AM.png" alt=""><figcaption></figcaption></figure>

4. If only partial boundary data is available from GeoPoDe, the missing levels will need to be created manually. Click on the Add Boundary Hierarchy Level button to add the missing boundary hierarchy levels.

<figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 9.59.34 AM.png" alt=""><figcaption></figcaption></figure>

5. For missing boundary levels, you can upload data via ShapeFiles or Excel. Download the Excel template if needed, fill in the missing boundary data, and upload it back into the system.

<figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 10.00.18 AM.png" alt=""><figcaption></figcaption></figure>

<figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 10.00.27 AM.png" alt=""><figcaption></figcaption></figure>

6. Preview and confirm the Boundary Data details. Use the filters to view different boundary levels or base maps (e.g., Satellite, Street Map). Click on the Confirm Boundary Data button to finalise the boundary data. A success screen will appear for 5 seconds before redirecting you to the Boundary Management home screen.

<figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 10.09.19 AM.png" alt=""><figcaption></figcaption></figure>

#### Steps for Creating Custom Boundary Data

1. If GeoPoDe data is not being used, click on Create My Own Boundary Data.
2. Add new boundary hierarchy levels using the Add New Boundary Hierarchy button. Name each level, and add up to 10 levels as needed.

<figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 10.17.50 AM.png" alt=""><figcaption></figcaption></figure>

3. Upload boundary data using either ShapeFiles or Excel. If using ShapeFiles for some levels and Excel for others, download the Excel template to ensure consistency. Fill in the boundary data for the levels not covered by ShapeFiles and upload the completed Excel file.

<figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 10.21.33 AM.png" alt=""><figcaption></figcaption></figure>

<figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 10.23.43 AM.png" alt=""><figcaption></figcaption></figure>

4. Preview the boundary data on a map or in Excel format. Use the filters to view different boundary levels or base maps. Click on Confirm Boundary Data to finalise the boundary data.

<figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 10.26.50 AM.png" alt=""><figcaption></figcaption></figure>

### Edit Existing Boundary Data

1. In the Boundary Management home screen, click on View Existing Boundary Data.
2. A table displays all existing boundaries with details such as Disease Type, Last Campaign Usage, and Creation Date.

<figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 10.28.33 AM.png" alt=""><figcaption></figcaption></figure>

3. To edit boundary data at the lowest level of the hierarchy, download the relevant ShapeFile or Excel.

<div align="left"><figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 10.29.54 AM.png" alt="" width="329"><figcaption></figcaption></figure></div>

4. Modify the data as needed.&#x20;

<figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 10.30.43 AM.png" alt=""><figcaption></figcaption></figure>

5. Save and upload the modified ShapeFile or Excel back into the system. Preview the updated boundary data and confirm the changes.

<div align="left"><figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 10.32.35 AM.png" alt="" width="321"><figcaption></figcaption></figure></div>

<figure><img src="../../../../.gitbook/assets/Screenshot 2024-08-26 at 10.33.12 AM.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
**Note:** Changes to boundary data will only apply to future campaigns. Ongoing campaigns will continue to use the boundary data with which they were created.
{% endhint %}
