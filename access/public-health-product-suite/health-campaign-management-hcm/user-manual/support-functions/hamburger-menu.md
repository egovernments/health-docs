# Hamburger Menu

## Overview

The hamburger button opens a list of actions on the user's screen. The top displays the user name and contact number, followed by other options such as the home button, language select, edit profile, projects, and logout.

## Steps

* Click on the hamburger menu to view the user profile and details.

### Edit Profile <a href="#edit-profile" id="edit-profile"></a>

* Click on the **Edit Profile** option on the hamburger menu.
* Edit the **User Name,** **Phone Number,** and **Gender** as required.
* Click on the **Save** button to save the edited information.
