# Specifications

This section provides a structured and comprehensive technical overview of DIGIT HCM. It is divided into three main segments:

1. [**Functional Specifications** ](functional-specifications/)– Detailed documentation of core modules, including campaign type setup, inventory management, beneficiary data handling, boundary hierarchies, system user roles, and more
2. [**Role Action Mapping**](role-action-mapping.md) – Defines the permissions and actions available to each system role—from system administrators to registrars, supervisors, warehouse managers, and programme managers—ensuring clarity, security, and accountability&#x20;
3. [**Building Blocks & Services** ](building-blocks-and-services.md)– Highlights the modular architecture of HCM, emphasising reusable, configurable building blocks—such as registries and service modules—that support adaptability, scalability, and seamless interoperability across campaigns and systems
