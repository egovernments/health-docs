# Customise Dashboard Views

* Date Filters: Each page has filters to view data for a specific date range, today's data, or cumulative data since the campaign's start.

![](https://lh7-us.googleusercontent.com/ajVi-_Liw_wUswHWIsDnKJuWfrmQs38W20qSTjrGayIw6OmM7wPrShQKLsasj3ZTkmXWQfW2i8vzdmVRUS8GeAHJuwv9fg7fUipEBKF5WWIpGkkkq3_shk7T-_mybPoTWBvUYzdl7khtS6fLDmK8pAk)

* Campaign Progress: A progression line at the top displays the number of days since the campaign began.

![](https://lh7-us.googleusercontent.com/PwOzNZfaqI8cZ076W65kuV_pXeSFpjCiIE5wLHthHbyMurMvH3sH5odTSBi_EzUZ4DFehI9I58v_xZzTmwjtfK4IHDhzoGVqYv-41PDVPfUVwUAykpjCpu2VkW8Z9bG_80r-NM14Bn1_lAMA6vuCERc)

* Data Completeness: The sync rate chart indicates how many users have synced data so far.

![](https://lh7-us.googleusercontent.com/wv3HVcg4cIUsVO9hhrtgVaddZ932vHB03jSvlEnluHZG12mc337V1JCUoWqwYpi5O_O2aJFUG4IdTpOIp_HapKuUguLqO5g6obtzK0wuKdCs5ucxxMf752Vld5QWoX1ID2vcBBnKO6fwqfEk6vBf1Eg)

* Drill-Down Charts: Double-click on any bar to drill down to sub-boundaries, continuing until the lowest level (e.g., a village). To return to the previous view, click the 'x' button.

![](https://lh7-us.googleusercontent.com/0cObORblKaap_rFVhylNUu1Ssdixe_UYd3PmkUvaG2fbLyNy_Sf8nqwQoCqm-b5_br-xWKX68aYaAjaEW1t67MQkwmPHz6r1Jpcxss-K_jycd39X0nmjZT4izlLyEfedePD8BnFRMvN3J6imcTfSOTQ)

* Toggle Chart Views: Switch between percentage and absolute values by clicking toggle buttons.

![](https://lh7-us.googleusercontent.com/UtYHc2Mp5zX3QxrUR7bIv8f5IWKfsPnpGv1285y217lY6FIZYoYqrxTn_eHU2elvmKBSNrz3T3fmV3SFCW-rYzMUHI88aYsPnXTJMQCz5QeMw823F9CCq86AtIvphUdFjruUOZMpwflsuaZdita_eVE)

* Prediction Line Chart: Estimates how many more days are needed to reach target coverage based on current service delivery rates.

![](https://lh7-us.googleusercontent.com/HnUmR-RyZi23HyaoffBHu8aqnd_5zWFOFHL9hE8LTeanwyx07m2_o6d_Gc-8YzvhychuKKMasvY9LQEUnoYZbIiBOlmtfp1ZEjahEaxMaLzFe3aCKbvTki9ce9B8TvG8ff3BiC4uuam8b_Hnk8WsliU)

* Sortable Tables: Summary tables can be sorted by column in ascending/descending order or alphabetically.

![](https://lh7-us.googleusercontent.com/YF0Voh7MYq09oJNMxeeQCv2vZ-amOZeHzTP3Jwb4N4pEwPe02dAcPGpZChFyxsEJk_kqVQhqkZcOF73mR41lRlROhPHbI89jYAMZKe5exWChOrCKFXFu2TxP87j60uHnfB7gSXUYFyKKuPKItq9uwAk)
