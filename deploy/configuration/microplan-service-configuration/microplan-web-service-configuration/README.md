# Microplan Web Service Configuration

## **HCM Microplan Web - Navigation Overview**

The HCM Microplan Web platform is designed to be easy to use, giving administrators and supervisors simple access to the tools they need for setting up microplans and managing data. The navigation is divided into two main sections: Set Up Microplan and Supervisor Flow.

***

#### [**Set Up Microplan**](./#set-up-microplan)

This section is intended for system administrators and users responsible for the initial setup of the microplan, configuration, and data management. The available options under this section include:

* [**Microplan Details**:](setup-microplan/microplan-details.md) Configuration of the fundamental details of the microplan, including objectives, timelines, and other key parameters.
* [**Boundary Selection**: ](setup-microplan/boundary-selection.md)Define and select the geographical boundaries (countries, provinces, districts, etc.) relevant for the microplan.
* [**Data Management**:](setup-microplan/data-management.md) Manage the population data and other datasets needed for the microplan, including data entry, updates, and validation.
* [**Microplan Assumptions**: ](setup-microplan/microplan-assumptions.md)Specify the assumptions that will guide the microplan, including factors like updated registry data, user roles, and collection methodology.
* [**Formula Configuration**:](setup-microplan/formula-configuration.md) Set up formulas and calculations used for resource distribution, target population estimates, or other metrics within the microplan.
* [**User Tagging:**](setup-microplan/user-tagging.md) The User Tagging Screen enables the Microplan admin to assign various roles to registered users, linking them to specific tasks and responsibilities within the microplan.
* [**Summary Screen:**](setup-microplan/summary-screen.md) The Summary Screen is a critical page in the microplan setup process, where system administrators and program managers can review, validate, and edit the data configured for the microplan. It provides.

***

#### [**User Management**](./#user-management)

This section allows administrators to manage users, assign roles, and control access levels for those interacting with the system. This ensures the security and integrity of the platform, with specific permissions for different types of users (e.g., system administrators, data collectors, reviewers).

***

#### [**Supervisor Flow**](./#supervisor-flow)

This section is tailored to supervisors who oversee the implementation and validation of the microplan. Key functionalities under this flow include:

* [**My Microplan**: ](supervisor-workflows/my-microplan.md)A personalised dashboard where supervisors can view and manage the microplan assigned to them.
* [**Select Activity**: ](supervisor-workflows/select-activity.md)Choose specific activities related to the microplan that need to be validated or reviewed.
* [**Validate and Approve Population Data**:](supervisor-workflows/validate-and-approve-population-data.md) Validate the collected population data and approve it for further processing and execution of the health campaign.
* [**Assign Facility to Villages**:](supervisor-workflows/assign-facility-to-villages.md) Assign health facilities to specific villages or regions, ensuring resources and health services are properly allocated.
