# HCM Dashboard Configurations

The **Dashboard Configurations** section describes how dashboards in the HCM platform are configured to display key metrics and insights. It covers settings that determine which data is shown, how it is grouped, and how visual elements are tailored for different roles and use cases.

These configurations help ensure that dashboards provide relevant, actionable information for supervisors, approvers, and administrators.
