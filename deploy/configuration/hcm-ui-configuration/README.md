# HCM UI Configuration

The **UI Configuration** section explains how user interface behaviour and screens in the HCM platform are customised through configuration. This includes layouts, field visibility, labels, supported workflows, and feature toggles that shape the user experience without requiring code changes.

These settings help tailor the UI to your programme’s processes, roles, and operational needs.
