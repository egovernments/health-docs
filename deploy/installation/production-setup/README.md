# Production Setup

This guide walks you through a step-by-step process for installing DIGIT HCM . Installation involves provisioning and configuring the hardware and network, as well as installing HCM services such as PostgreSQL, Elasticsearch, Apache Kafka, and DIGIT HCM services like API Gateway and User Service. DIGIT HCM can be installed on public clouds, such as AWS or Azure, or on a Private Cloud. Installing DIGIT on personal computers is not recommended.

Follow the steps outlined in the sections below to install HCM in the production environment.
