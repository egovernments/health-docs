# 1. Configuration

## Helmfile <a href="#helmfile" id="helmfile"></a>

Update the environments as required with their relevant file-paths of environment & secrets file and the namespace to be used.

In below config `"demo"` is the environment with default namespace being set & environment files being provided.

{% code lineNumbers="true" %}
```
# config-as-code/helm/charts/monitoring/monitoring-helmfile.yaml

environments:
  demo:
    values:
      - namespace: monitoring
      - ../../../environments/egov-demo.yaml
      - ../../../environments/egov-demo-secrets.yaml
```
{% endcode %}

## Environment Configuration <a href="#environment-files" id="environment-files"></a>

### Grafana <a href="#grafana" id="grafana"></a>

1. GitHub OAuth App Creation
   * Follow the [GitHub OAuth app](https://docs.github.com/en/developers/apps/building-oauth-apps/creating-an-oauth-app)
   * Homepage URL\
     `https://<your_domain_name>`
   * Authorization callback URL\
     `https://<your_domain_name>/monitoring/login/github`
   * Generate `Client ID` & `Client secret`
2.  Update `Client ID` & `Client secret` in secrets config.

    <pre data-line-numbers><code># config-as-code/environments/egov-demo-secrets.yaml

    cluster-configs:
      secrets:
        grafana:
          clientID: &#x3C;OAuth-key>
          clientSecret: &#x3C;OAuth-token>
    </code></pre>


3.  Update environment config to allow GitHub organization & teams specific role-based access

    <pre data-line-numbers><code># config-as-code/environments/egov-demo.yaml

    grafana:
      github:
        allowed_organizations: ["&#x3C;organization>"]
        role_attribute_path: contains(groups[*], '@&#x3C;organization>/&#x3C;team>') &#x26;&#x26; 'Viewer'
    </code></pre>

{% hint style="info" %}
**Note:** Valid roles are `None`, `Viewer`, `Editor`, `Admin` or `GrafanaAdmin`\
Visit official documentation for more information [Grafana GitHub OAuth](https://grafana.com/docs/grafana/latest/setup-grafana/configure-security/configure-authentication/github/#configure-role-mapping)
{% endhint %}

### Loki Stack <a href="#loki-stack" id="loki-stack"></a>

#### **Filesystem as a storage**

{% code lineNumbers="true" %}
```
# config-as-code/environments/egov-demo.yaml

loki:
  persistence:
    enabled: true
    accessModes:
      - ReadWriteOnce
    size: 15Gi
  serviceAccount:
    annotations: {}
  additionalConfigs:
    schema_config:
      configs:
        - from: 2020-10-24
          store: boltdb-shipper
          object_store: filesystem                 ## local filesystem as storage
          schema: v11
          index:
            prefix: index_
            period: 24h
    storage_config:
      boltdb_shipper:
        active_index_directory: /data/loki/index
        cache_location: /data/loki/index_cache
        shared_store: filesystem                  ## local filesystem as storage
        cache_ttl: 24h
      filesystem:
        directory: /data/loki/chunks
    compactor:
      working_directory: /data/loki/boltdb-shipper-compactor
      shared_store: filesystem                    ## local filesystem as storage
      retention_enabled: true
      compaction_interval: 72h                    ## compaction in hours
    table_manager:
      retention_deletes_enabled: true
      retention_period: 72h                       ## retention in hours
```
{% endcode %}

#### **AWS s3 as storage**

**Caution:** Use the `sub` claim instead of `aud` when setting up Web Identity (OIDC) IAM roles to ensure correct identity matching.

{% hint style="warning" %}
**Caution:** Use the `sub` claim instead of `aud` when setting up Web Identity (OIDC) IAM roles to ensure correct identity matching.
{% endhint %}

1.  Create AWS Web Identity (OIDC) IAM role with following policy.

    <pre data-line-numbers><code>{
        "Version": "2012-10-17",
        "Statement": [
            {
                "Sid": "AccessToLokiBucket",
                "Effect": "Allow",
                "Action": [
                    "s3:PutObject",
                    "s3:GetObject",
                    "s3:DeleteObject",
                    "s3:ListBucket"
                ],
                "Resource": [
                    "arn:aws:s3:::&#x3C;s3-bucket>",
                    "arn:aws:s3:::&#x3C;s3-bucket>/*"
                ]
            }
        ]
    }

    </code></pre>

    &#x20;
2.  Update s3 details & role ARN in below config.

    <pre data-line-numbers><code><strong># config-as-code/environments/egov-demo.yaml
    </strong><strong>
    </strong>loki:
      persistence:
        enabled: true
        accessModes:
          - ReadWriteOnce
        size: 10Gi
      serviceAccount:
        annotations:
          eks.amazonaws.com/role-arn: &#x3C;s3-role-arn>    ## AWS arn for s3 role 
      additionalConfigs:
        schema_config:
          configs:
            - from: 2020-10-24
              store: boltdb-shipper
              object_store: s3                         ## AWS s3 as storage
              schema: v11
              index:
                prefix: index_
                period: 24h
        storage_config:
          boltdb_shipper:
            active_index_directory: /data/loki/index
            cache_location: /data/loki/index_cache
            shared_store: s3                           ## AWS s3 as storage
            cache_ttl: 24h
          aws:
            s3: s3://&#x3C;region>/&#x3C;s3-bucket>              ## s3 region &#x26; bucket
        compactor:
          working_directory: /data/loki/boltdb-shipper-compactor
          shared_store: s3                             ## AWS s3 as storage
          retention_enabled: true
          compaction_interval: 168h                    ## compaction in hours
        table_manager:
          retention_deletes_enabled: true
          retention_period: 168h                       ## retention in hours
    </code></pre>

        account_key: xyzdadasdadadadda        # For the account-key, see docs: https://docs.microsoft.com/en-us/azure/storage/common/storage-account-keys-manage?tabs=azure-portal

        request_timeout: 0

**Slack Alerts**

{% code lineNumbers="true" %}
```
# config-as-code/environments/egov-demo-secrets.yaml

cluster-configs:
  secrets:
    alertmanager:
      config:
        global:
          slack_api_url: https://hooks.slack.com     ## slack webhook URL
          resolve_timeout: 5m
        route:
          group_by: ['alertname']
          group_wait: 30s
          group_interval: 5m
          repeat_interval: 10m
          routes:
          - receiver: slack-notification
            match:
                severity: "warning|critical"
            continue: true
        receivers:
        - name: slack-notification
          slack_configs:
            - channel: '<slack-channel>'             ## slack channel
              send_resolved: true
              username: 'Alertmanager'
              title: |
                  [{{ .Status | toUpper }}{{ if eq .Status "firing" }}:{{ .Alerts.Firing | len }}{{ end }}] {{ .CommonLabels.alertname }}
              text: |-
                  {{ range .Alerts -}}
                  {{- "\n" -}}
                  *Alert:* {{ .Annotations.summary }}
                  {{ if .Labels.severity }}*Severity:* `{{ .Labels.severity }}`{{ end }}
                  *Cluster:* {{ .Labels.cluster }}
                  *Details:*
                  {{ .Annotations.description }}
                  {{ end }}
              color: |-
                  {{ if eq .Status "firing" -}}
                    {{ if eq .CommonLabels.severity "warning" -}}
                      warning
                    {{- else if eq .CommonLabels.severity "critical" -}}
                      danger
                    {{- else -}}
                      #439FE0
                    {{- end -}}
                  {{ else -}}
                    good
                  {{- end }}
```
{% endcode %}

{% hint style="info" %}
**Note:** Generate [Slack Incoming Webhook](https://api.slack.com/messaging/webhooks) & update `slack_api_url` under global config & `slack-channel` under receivers config.
{% endhint %}

**Email Alerts**

{% code lineNumbers="true" %}
```
# config-as-code/environments/egov-demo-secrets.yaml

cluster-configs:
  secrets:
    alertmanager:
      config:
        global:
          resolve_timeout: 5m
        route:
          group_by: ['alertname']
          group_wait: 30s
          group_interval: 5m
          repeat_interval: 10m
          routes:
          - receiver: email-notification
            match:
              severity: "warning|critical"
            continue: true
        receivers:
        - name: email-notification
          email_configs:
            - to: '<recepient-email-address>'             ##  reciever's email id
              from: '<sender-email-address>'              ##  sender's email id
              smarthost: 'smtp.gmail.com:587'             ##  "" Update SMPT
              auth_username: '<sender-email-address>'     ##  configuration
              auth_password: '<auth-token>'               ##  as per the provider ""
              send_resolved: true
              headers:
                subject: |
                  [{{ .Status | toUpper }}{{ if eq .Status "firing" }}:{{ .Alerts.Firing | len }}{{ end }}] {{ .CommonLabels.cluster }} - {{ .CommonLabels.alertname }}
              html: |
                <html>
                <head>
                <title>Alert!</title>
                </head>
                <body>
                {{ range .Alerts.Firing }}
                <ul>
                <li> <b>Alert Name:</b> {{ .CommonLabels.alertname }} </li>
                <li> <b>Severity:</b> {{ if eq .Labels.severity "critical" }}<b style="color:red;">CRITICAL</b>{{ else if eq .Labels.severity "warning" }}<b style="color:orange;">WARNING</b>{{ else }}<b>{{ .Labels.severity | toUpper }}</b>{{ end }} </li>
                <li> <b>Summary:-</b> {{ .Annotations.summary }} </li>
                <li> <b>Cluster:-</b> Cluster </li>
                <li> <b>Details:</b>
                  <p style="margin-left: 20px;"> {{ .Annotations.description | replace "\n" "<br>" }} </p>
                </li>
                </ul><br>
                {{ end }}
                </body></html>
```
{% endcode %}

**Note:** Follow this [article](https://support.google.com/a/answer/176600?hl=en) in order to setup SMTP server for Gmails
