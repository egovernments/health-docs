# Select Project

## **Overview**

The Select Project allows supervisors to select a project and view or manage attendance registers associated with that project.

## **Interface Elements**

<figure><img src="../../../../../.gitbook/assets/image (179).png" alt=""><figcaption></figcaption></figure>

<table><thead><tr><th width="188.109375">Element</th><th>Description</th></tr></thead><tbody><tr><td>Project Selection</td><td><ul><li>Dropdown to select the project</li></ul></td></tr><tr><td>Action Buttons</td><td><ul><li>Back: Navigate to the previous page.</li><li>Next: Proceed to the attendance registers for the selected project.</li></ul></td></tr></tbody></table>

## **User Actions Flow**

1. Select a Project: Choose a project from the dropdown list.
2. Proceed to Next Screen: Click "Next" to access the registers associated with the project.
