# Beneficiary IDGen

## Overview

The Beneficiary IDGenId feature is to link a unique ID to an individual. UniqueId’s are fetched from the server with the unique DeviceId and user.&#x20;

## Key Feature

1. Fetching UniqueID’s from the server with device and user combination
2. Added new ID\_TYPE - UNIQUE\_BENEFICIARY\_ID to link individuals
3. Added search with UNIQUE\_BENEFICIARY\_ID
