# Installation

The DIGIT HCM installation comprises three steps to create a new production-ready server that can be scaled on demand. The installation process is currently supported only for AWS. However, support for other cloud platforms such as Azure and GCP will be available in the future.

**Step 1:** [**Execute GitHub Action for installation**](install-using-github-actions-in-aws.md): Execute a GitHub action for the installation process.&#x20;

**Step 2:** [**Execute the Postman Collection for Minimum Setup Data**](execute-seed-data.md): Execute the minimum setup data required to run a campaign&#x20;

**Step 3:** [**Generating the APK for the Server**:](../../products/health-campaign-management/frontline-workers-app/installation/app-setup.md) Generate the APK pointing to the above-mentioned server.
